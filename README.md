# LOVE LOVE 

## Website Name

**LOVE LOVE**



## Website Structure

### 1. Header

Logo | Home | Profile | Hobbies | Login

### 2. Hero Section

Large dark rose banner with a welcome message.

**Text**

My Hobbies!!

**Buttons**

- Join now
- View my profile

### 3. How It Works

Display in cards.

- 1. Create a profile
- 2. Share your hobbies
- 3. Start chatting

### 4. Featured Members

Display in cards.

- Name and age
- Short description of their hobbies
- [View profile]

Repeat for 3-6 members.

### 5. Profile Page

- Profile photo
- Name and role
- Short bio
- Send a like button
- Details: Location, Email, Status, Joined
- Skills shown as tags

### 6. Hobbies Page

- Unordered list of hobbies
- Numbered list of hobbies
- Back to profile link

### 7. Login Page

- Username field
- Password field
- Log in button
- Error message when the login is wrong
- After login, the nav shows Logout
